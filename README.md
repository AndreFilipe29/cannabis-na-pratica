# Cannabis na Prática · site da mentoria

- `index.html` — página de inscrição da aula aberta (grava na tabela `leads`).
- `aluno.html` — área do aluno + painel admin (login por link no e-mail).
- `config.js` — URL e chave pública do Supabase.
- `supabase/` — estrutura do banco (schema.sql) e conteúdo inicial (seed.sql).

Hospedagem: GitHub Pages (grátis). Banco: Supabase plano Free (projeto separado da Cannabiatria).
